| ESLint | `npm run lint` — успешно после исправления исходной несовместимости плагинов. |
| Backend | `node --check`, запуск в контейнере, `/health/live` и `/health/ready` — успешно. |
| SQL | Job в Compose создала таблицу; повторный запуск образа и SQL прошёл без удаления строк. |
| Docker build | Оба образа собраны для linux/amd64: локально `coin-app:latest` и `coin-db-init:latest`. |
| Compose | `docker compose up --build -d`: MySQL healthy, db-init завершился с кодом 0, приложение запущено. |
| REST CRUD | Создание, чтение одной записи и списка, изменение и удаление — успешно. Две покупки одной монеты имеют разные ID. |

| Безопасность зависимостей | После обновления backend `npm audit --omit=dev` — 0 уязвимостей. В исходном инструменте ESLint обнаружены предупреждения moderate в дереве dev-зависимостей; они не входят в финальный контейнер backend. |

Повтор интеграционных тестов: при работающем Compose из корня `node tests/integration.mjs`. Скрипт создаёт тестовые строки, повторно запускает SQL-инициализацию и перезапускает контейнеры приложения и базы; удаляет созданные им строки.

Не проверены: публикация в Docker Hub, серверная валидация Kubernetes, Percona, ProxySQL, MetalLB, развёртывание на ВМ и фактическая отказоустойчивость.
